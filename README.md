# Assignment 2 – ReAct AI Agent

## Project Overview

This project implements a **ReAct (Reasoning and Acting) AI Agent** using Python and the Google Gemini API. The agent uses a search tool to retrieve relevant information from documents and provides intelligent, context-based answers to user queries.

The project demonstrates how AI agents can combine reasoning, action, and external tools to solve information-retrieval tasks.

## Objectives

- Build a ReAct-based AI agent.
- Integrate the Google Gemini API.
- Implement a document search tool.
- Enable AI-powered question answering.
- Understand the interaction between reasoning and external tools.

## Technologies Used

- Python
- Google Gemini API
- Google Colab
- Jupyter Notebook
- GitHub

## Key Features

- **Document Search:** Searches relevant information from available documents.
- **AI-Powered Question Answering:** Generates answers using the Gemini API.
- **ReAct Agent Implementation:** Combines reasoning and actions through a search tool.
- **Interactive Execution:** Runs through Google Colab.

## Setup and Installation

### 1. Open Google Colab

Open the project notebook using Google Colab.

### 2. Configure Gemini API

1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Sign in with your Google account.
3. Create a Gemini API key.
4. Store the API key securely in Google Colab Secrets.

**Important:** Never share your API key or upload it to a public GitHub repository.

### 3. Run the Notebook

1. Open `Assignment_2_ReAct_Agent.ipynb`.
2. Connect your Google Colab environment.
3. Configure the required API key.
4. Complete all TODO and User Input sections.
5. Run the notebook cells.
6. Resolve any execution errors if they occur.
